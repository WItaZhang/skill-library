## 实现

App 新增可选 updateSource；生产连接须注入 SkillUpdateSource，Actor 与认证仍由宿主拥有。编辑器按团队及当前 Skill 过滤已提交事件，序号去重，连续事件合并为权威 getSkill 查询；打开及重连均核对，卸载取消监听。事件不修改草稿正文、修订或基线。

过期草稿可继续编辑及保存不完整文本，发布受阻。previewDraftUpdate 传递未保存输入，展示基础、本地、最新、双方差异、候选及明确冲突选择。无重叠也须勾选确认。applyDraftUpdate 携带服务令牌、目标与修订，以共享服务接口原子保存内容及基线。目标、修订、本地输入变化使预览失效；手动文本和删除选择在刷新时保持可见，即使新版已无该冲突，也需重新检查旧选择。

互斥请求守卫防止保存/预览/同步/发布竞态；比较打开时暂停自动保存。保存响应不替换输入。同步请求期间若继续输入，显示服务端已同步内容供对照，保留本地输入，持续暂停自动保存和发布，直到作者明确确认整合；不会把旧基线整包内容自动写回。发布超时后保留完整原请求与幂等键，提供显式原请求重试，成功显示自动生效且不丢后续输入。

viewer 中已有维护者按服务既有授权可编辑；其他 viewer 不能编辑，作者/团队保护仍由服务强制执行。会话组件、任务快照及 D1-D3 暂定策略未改动。

## 边界、假设与待组合验收

- 本地演示为内存、按文件三方比较与事件源；不能证明真实服务事务、SQLite 回滚、持久幂等、文本级合并、跨进程 SSE 或生产安全。生产 client/source 须通过 App 注入，真实服务/broadcast 的组合验收由协调端完成。
- 前端只调用共享 v2 接口；依赖服务强制作者权限、当前编辑授权、预览令牌及目标/修订校验、原子应用、发布与事件一致性。网络层必须提供规范 DomainError。
- 出现服务端变更但客户端尚未知时，服务仍须拒绝 stale apply/publish；前端保留输入并提供服务器草稿对照恢复。事件自身不是变更草稿依据。
- 请求中的纯本地输入只在当前编辑器内保留；浏览器关闭不将正文备份到本地存储，保留既有离开提示策略。身份变化由宿主重挂载 App。
- 真实 Agent、生产认证、首次创建技能表单、管理审计 UI、容量、二进制资源及跨库任务接受排序不在本次范围。任务隔离及 D1-D3 保持原语义，没有宣称修复宿主跨库边界。
- 供组合验收使用的代码 SHA 如上；用户自行管理合并。分支和 worktree 保留。
